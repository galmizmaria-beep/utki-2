# Новые возможности

В разделе «Раунды» поставьте курсор в вопрос или ответ и загрузите картинку через «Картинка в задание». Изображение сохраняется в проекте и HTML. Можно использовать запись `![Описание](https://адрес/картинка.png)`.

Устное задание: `[устно] Ваш вопрос | Пояснение`. Пояснение видно только после «Проверить».

В библиотеке включите «Выбирать несколько целей» и нажмите нужные изображения. Можно загрузить несколько файлов сразу. Набор отображается над библиотекой; кнопка с крестиком удаляет цель. Количество одновременно летящих целей задаётся в сложности. Если целей в наборе больше, чем одновременно на экране, увеличьте количество в сложности (до 6).

В предпросмотре «Цель» перетаскивайте цели за зелёную пунктирную рамку. Координаты сохраняются; движение начинается с этих мест. Доступны строго прямо (вправо), строго влево, строго вправо, строго вверх и строго вниз. «Прямо» означает горизонтально вправо.

Поведение цели при попадании:
- Падение с вращением
- Плавное исчезновение
- Уменьшение
- Вихрь
- Взлёт вверх
- Вспышка с увеличением
- Переворот

Отдельно выбирается эффект частиц: звёздная вспышка, конфетти, облачко, пиксели, искры, световое кольцо, радуга, снежинки, сердечки, молния, пузыри, фейерверк, клякса, глитч, растворение или без частиц.

Новая версия: `game-v20261022-features1.html`, плеер `player-v20261022-features1/`. Прежние выпуски сохранены локально без изменений и не включены в репозиторий utki-2.

Проверено в Chrome с реальным временем: export, runtime-parity, result-button, pinned-player, features — PASS. Последняя проверка охватывает редактор и новый снимок плеера.
